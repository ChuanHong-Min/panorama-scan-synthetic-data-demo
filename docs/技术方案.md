# 技术方案：从绝对位姿到训练样本

## 1. 为什么不能只做相邻帧拼接

当扫描方向变成斜线、弧线或 S 形时，相邻帧之间的外观变化可能很大；一旦某次局部对齐错误，误差会沿扫描轨迹累积。项目因此引入点云标定底图，让每一帧都能回到统一的全局坐标系。

## 2. 正向链路：点云底图 → 真值位姿

1. 采集带点阵的标定底图；
2. 用 Sobel 梯度特征和模板匹配估计相邻帧的相对关系；
3. 用 SVD 刚体配准把相对运动转换到全局坐标；
4. 输出每帧的位置、旋转、缩放、形变和光照相关信息；
5. 用不良帧率指标筛掉位姿不稳定的轨迹。

点云底图只承担标定和矫正职责，不作为模型训练图像。

## 3. 逆向链路：真值位姿 → 训练图像

对页面内容按逐帧位姿执行透视、旋转、缩放和单应性逆变换，得到“该帧相机看到的样子”，再叠加纸张纹理、光照和反光退化。这样同时保留内容分布、运动轨迹分布和精确标签。

## 4. 难例驱动迭代

初版随机角度合成后，评测发现相交区域单行、几何图和表格效果不足。后续先增加严格 `60° / 90°` 姿态，再用 OCR 自动定位页面中的几何图和表格区域，生成针对性难例并进入下一轮训练。

## 5. 可公开复现边界

公开版本可以提供自制页面、随机轨迹、透视变换和质量筛选的最小演示；不包含内部标定底图、未授权教材内容、生产数据路径、模型权重或完整训练脚本。

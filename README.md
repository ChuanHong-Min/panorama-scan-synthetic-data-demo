# 词典笔任意姿态扫描：合成数据与逆向重建

> 项目案例说明
>
> 本仓库用于展示项目思路、技术路线和脱敏后的可视化材料。公开版本不包含内部源代码、训练数据、模型权重、服务地址或生产配置。

## 项目简介

传统词典笔扫描通常依赖相对稳定的扫描角度、速度和方向。这个项目围绕“任意姿态扫描”构建训练数据体系：覆盖笔身与纸面 `0°–90°` 夹角、横扫 / 斜扫 / 弧线 / S 形 / 画圈等轨迹，并支持整页扫描场景。

个人职责是从 0 到 1 设计并实现全景拼图模型的训练数据合成链路，而不是简单做图像增强。核心思路是先用点云标定底图求解逐帧绝对位姿，再根据页面内容和位姿标签逆向重建模型训练时看到的图像。

## 关键结果

- 累计产出约 **75 万条**带精确位姿真值的合成训练样本；
- 单行扫描数据从约 **14.3 万条**高质量轨迹；
- 覆盖单行扫描、整页扫描、严格 `60° / 90°` 姿态、几何图和表格难例；
- 以上指标来自内部项目记录，公开版本只保留经过人工确认的汇总信息。

## 技术关键词

`Synthetic Data` · `Point-cloud Registration` · `Homography` · `Inverse Reprojection` · `Sobel` · `Template Matching` · `SVD` · `Hard-example Mining`

## 技术路线

```text
点阵标定底图
    ↓
帧间特征对齐 + SVD 刚体配准
    ↓
逐帧绝对位姿与光照估计
    ↓
真实课本页 + 复合逆变换
    ↓
透视 / 旋转 / 缩放 / 光照 / 反光退化
    ↓
带精确位姿标签的训练样本
    ↓
评测定位弱项 → 定向造数 → 复训验证
```
